检查覆盖页面、Astro/Svelte 组件、布局、内容 schema 与读取逻辑、Markdown 插件、后台脚本与表单、工具脚本、样式与翻译、Netlify 配置和 GitHub Actions。

## 本次修复

- 原后台默认草稿导致新内容在生产站点隐藏：新建内容默认公开；已确认用户用于验证发布的「测试」文章在远端为 `draft: true`，此次将其改为公开，其他原有草稿保留原状态。
- 删除最后一篇公开博客后首页不再生成：提供空博客首页，并隐藏无意义的分页。
- 栏目清空后内容缓存可能保留旧条目：生产构建使用 `astro build --force`。
- 分类前后空格导致归档筛选不匹配；特殊分类名如 `__proto__` 导致计数异常：统一分类名称并使用无原型计数表。
- 本地封面路径错误导致整站构建失败：缺失封面显示占位内容并输出可定位的警告。
- 博客标题含 `</script>` 时截断 JSON-LD：在嵌入脚本前转义小于号。
- PDF-only 笔记空正文导致构建失败；草稿引用缺失附件阻止其他内容部署：支持空正文，只验证已公开条目的附件存在性。
- 导航旧主题切换逻辑与 Svelte 控件重复处理：交由 Svelte 统一管理深浅色状态。
- 浮动面板未加载时点击外部导致异常；菜单关闭后展开状态不一致：空值保护并同步 aria-expanded。
- 文章目录移除事件监听时遗漏 capture 参数：匹配注册方式清理监听。
- GitHub 卡片指令将未验证的仓库名插入脚本：限制为安全的 owner/repo 格式。
- 本地文章生成器可写出文章目录，且特殊标题未正确编码为 YAML：限制路径，使用带引号的标题并防止覆盖文件；不生成尚未配置支持的 MDX。
- 归档日期受访客时区影响：与文章日期统一使用 UTC 日期字段。
- 图标集合配置误填 Svelte 预处理器字符串：更正为实际使用的 material-symbols 集合。
- GitHub Actions 使用漂移的 Biome latest 和只生成 Astro 页面：固定到项目的 Biome 版本，并检查完整构建与内容发布回归。
